A FEW GOOD QUESTIONS

Before your next move.

Do I need to connect my GitHub account?

For the current version, enter your username to import public repository descriptions, primary languages, and READMEs. No GitHub password or token is required. To include private repositories you own, configure a read-only GitHub token in the local environment.

Does it apply to jobs automatically?

The workspace generates downloadable PDFs, prepares configured application forms with Playwright, and can submit after you review and explicitly approve the exact application. A form mapping and a confirmation message are required.

How does matching work?

The workspace compares recognized skills in the job description with your saved CV and imported repository evidence. It combines keyword evidence matching with optional source-linked LLM tailoring. You review AI wording before saving. Coverage is a guide for review, not an ATS score or a prediction.

Where is my information saved?

Your profile, repository imports, and application versions are saved in PostgreSQL on this computer. Public repository imports make requests to GitHub.
